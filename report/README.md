# report/

The research paper style report (max 20 pages) goes here, written in the NCI
MSc Word or LaTeX template from Moodle. It is not generated by the code.

Mandatory sections (handbook): Abstract, Introduction, Literature Survey,
Research Methodology, Design and Implementation Specifications, Evaluation,
Conclusions and Discussion, References.

## What the artefact gives you to cite in the report

| Report section | Source in this repo |
|----------------|---------------------|
| Design and Implementation | `template.yaml`, `docs/ARCHITECTURE.md` (diagrams, fault model) |
| Methodology | `configs/*.yaml` (IVs, levels, repeats), `configs/analysis_plan.yaml` (tests fixed before collection) |
| Evaluation - tables | `results/summary/hypotheses.md`, `results/summary/stats_*.json`, `results/*/summary.csv` |
| Evaluation - figures | `results/figures/*.png` |
| Reproducibility | `results/**/manifests/<RUN_ID>.json` (git sha, config hash, seed, fault schedule) |

Important: everything currently in `results/` was produced by the local
simulator (`backend: localsim` in every manifest). If the report presents
numbers, it has to say whether they come from the simulator or from live AWS
runs, and simulator numbers must not be described as AWS measurements.
